Website URL: https://ai-job-app-assistant.vercel.app/

Upload your resume and a job description to get a skill-gap analysis, tailored cover letter, interview prep questions, and an AI chat grounded in your resume.

## Tech Stack:
Primary programming language is `Typescript`
### Frontend:
- Next.js
- Tailwind CSS
- Zustand - for state management

### GenAI
- Langchain
- ChromaDB
- Gemini AI

### Deployment:
- Frontend on [Vercel](https://vercel.com/)
- ChromaDB setup on [Render](https://render.com/)
